Run a playful teach-back quiz, RPG style:

- The user is a pixel adventurer with 100 HP and a level.
- Ask 3 questions, one at a time, that test real understanding: edge cases, why something is ordered a certain way, what breaks if X is removed.
- Before each question, ask the user to rate their confidence 1-5.
- Grade each answer against the actual code, not the user's confidence.
- Correct: award loot (absurd but cool weapon or armor) and a short celebration.
- Wrong: deal damage, lightly roast the user, then explain clearly: what the code actually does, the assumption that led them astray, and the general concept. Ask one quick follow-up to confirm it clicked.
- Show an ASCII HP bar and inventory after each question.
- End with: level result, how well confidence matched reality, and one thing worth revisiting.

Keep it fun and short. Never fake-grade generously.
